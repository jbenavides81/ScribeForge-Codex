# If something goes wrong

## A file won't open

- **"It may be damaged, or it may not really be a PDF"**: the file is broken, or is another kind of file with a `.pdf` name. Try getting a fresh copy from where it came from.
- **"It may have been moved, renamed or deleted"**: the file isn't where it was. Open it from its new place.
- **"Larger than 1 GB"**: ScribeForge opens files up to 1 GB.
- **"Couldn't be read"**: check that the file isn't open in another program that's locked it, then try again.

## It asks for a password

The file is protected. Type its password; ScribeForge never saves it. If you don't know the password, the file can't be opened.

## A file can't be saved

- If Windows says the file is in use, close it in the other program, or save under a different name.
- If ScribeForge says it couldn't make the new file, the original may hold something it can't copy. The message says what went wrong.

## "Windows protected your PC" when installing

The ScribeForge installer isn't signed with a paid certificate, so Windows shows this warning the first time. Click **More info**, then **Run anyway**.

## Settings went back to their defaults

The settings file was damaged. ScribeForge kept the old file next to the new one (its name says it was set aside) and started with its defaults. Choose your settings again.

## Text can't be selected

The page may be a scan, or a page that was redacted: it's a picture, with no text in it.
