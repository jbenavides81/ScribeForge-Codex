# ScribeForge

An open-source, offline PDF toolkit for Windows: view, organise, annotate, inspect and redact PDFs, with signing and an encrypted archive to follow. ScribeForge is a BC6 app.

**Status:** planning. There's no code yet. The next step is the Phase 0 plan.

ScribeForge never sends anything over the network, and it never changes the files you open: edits save to a new file.
