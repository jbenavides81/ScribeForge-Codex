# Getting started

ScribeForge opens, reads and edits PDF files on your computer. It never connects to the internet, and it never changes the files you open: everything you do is saved to a new file.

## Opening a PDF

- On **Start**, click **Open a PDF…** (or press `Ctrl+O`), or drag a PDF file onto the window.
- Files you've opened before are listed under **Recent files**. Click one to open it again.
- If a file needs a password, ScribeForge asks for it. The password is never saved.

## The screens

Use the list on the left to move between screens.

| Screen | What it's for |
|---|---|
| Start | Open a file, or one you opened before |
| Document | Read the file, find text, add annotations and mark text to redact |
| Pages | Rearrange, turn, delete, merge and split pages |
| Details | See and change the file's title and author, and see everything else it carries |
| Settings | Theme, text size and other choices |
| Help | These pages |
| About | The version, and the licences of the parts ScribeForge is built from |

## Saving

Whatever you change (pages, annotations, details or redaction), you save it as a **new file**. Your original stays exactly as it was. See [Saving and your original files](07-saving.md).
