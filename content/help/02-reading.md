# Reading a PDF

The **Document** screen shows your file.

## Moving around

- Scroll, or use the arrows next to the page number. You can also type a page number and press `Enter`.
- Click **Thumbnails** (or press `Ctrl+T`) to show or hide small pictures of the pages. Click one to go to that page.
- Zoom with **+** and **−**, or choose **Fit width**, **Fit page** or a percentage from the list.

## Finding text

Type in **Find in document** (or press `Ctrl+F` to jump there). ScribeForge shows how many matches there are and highlights them. Press `Enter` for the next one, or `Shift+Enter` for the one before.

## Copying text

Select text with the mouse and press `Ctrl+C`. In a file that's a scan, or a page that was redacted, there may be no text to select.

## Links

- Links to another page in the same file just go there.
- Web links show you the address first and ask before opening it in your web browser. ScribeForge itself never goes online.
- Links that would run a program or a script are never followed.

## Files ScribeForge can't open

If a file is damaged, isn't really a PDF, or is larger than 1 GB, ScribeForge says so in plain words and keeps working. See [If something goes wrong](11-troubleshooting.md).
