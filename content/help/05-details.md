# Details and what a file carries

The **Details** screen (or `Ctrl+Shift+D`) shows facts about the open file, and everything it holds besides what's on its pages.

## Document details

You can change the **Title**, **Author**, **Subject** and **Keywords**. Your changes go into the new file when you save, and **Undo my changes** puts the file's own values back.

A PDF keeps these details twice: once in a classic list, and once in a format called XMP that many programs read first. ScribeForge always writes both, matching. If the two copies in your file disagree, or the XMP copy can't be read, the Details screen tells you.

## About this file

Which program made the file, when it was created and last changed, its PDF version, its page sizes, and whether it has a password or restrictions.

## What this file carries

- **Details**, including any extra ones another program added (such as a company name).
- **Attached files**, for the whole document or on a page.
- **Form fields**, and whether they're filled in.
- **Comments**, and who wrote them.
- **Scripts and actions** that could run code, open a program or send data. ScribeForge never runs them.
- **Bookmarks**.
- **Layers**, including hidden ones. What's on a hidden layer is still in the file, and anyone can show it.
- **Links**: web and email addresses, and links to pages.
- Whether the file has a **password or restrictions**.

Before every save, ScribeForge shows the same list for the new file, so nothing goes out by surprise. You can turn that off in **Settings**.
